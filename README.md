## What I work on

**⚡ Electronics & hardware** — the biggest pull for me. Microcontrollers,
sensors, motors, custom PCBs, and the mechanical side of it: CAD, 3D printing,
and getting real hardware to do what the datasheet promised. Most of my projects
cross disciplines — the 3-wheel car needed electronics, mechanical design and
firmware at once.

**🔐 Security** — web application security, CTFs, and deliberately vulnerable
labs. I care about the boring parts: access control, session handling, and the
kind of bug that hides in plain sight next to correctly-escaped code.

**🌐 Web** — PHP and small full-stack tools. My preference is boring,
predictable tooling over clever abstractions.

**🎮 Games** — Godot and GDScript, mostly 2D.

## Projects

| Project | What it is |
|---|---|
| **[3-Wheel Car](https://github.com/RataDarius/3-wheel-car)** | An autonomous car built over three prototypes. Arduino Nano and ESP32 for control, DC motors on the wheels, servo steering through a custom linkage with 3D-printed gear reduction, an ultrasonic sensor for obstacle avoidance and an ESP32-CAM for vision. Chassis, servo stand and gear sets designed in OnShape and printed locally. Built under the Tinerii Cercetatori (Young Researchers) program — full parts list, steering mechanism and build documentation included. |
| **[SecureBank](https://github.com/RataDarius/bank-app)** | A deliberately vulnerable banking application built as a CTF / pentest lab. PHP 8.2 + MySQL 8 in Docker, three role tiers, and a Puppeteer bot that plays the administrator on a 10-second loop. The intended solve runs from exposed credential files, through stored XSS in the staff forum, to stealing the admin's live session cookie — with a full writeup in the repo README. |
| **[Starlight](https://github.com/RataDarius/first-game)** | A 2D platformer in Godot 4.4. Coins, enemies, killzones, and a slime that will not go away. |
| **[Portfolio](https://github.com/RataDarius/mysite.github.io)** | Static site on GitHub Pages. Hand-written HTML and CSS, no build step. |
